# 第一阶段文件各自做什么

| 目录 | 内容 | 是否提交GitHub |
|---|---|---|
| `router/app/` | 输入校验、任务分类、选路、作业持久化、GPU租约、答案解析和API | 是 |
| `router/workers/` | 三条推理路线的JSONL进程包装器 | 是 |
| `router/tests/` | 原有路由、解析、GPU调度与任务生命周期单元测试 | 是 |
| `router/config/` | 配置说明；实际YAML由配置脚本生成 | 说明是，本机配置否 |
| `integrations/qwen/` | 通用路线加载函数、训练入口、完整元数据评测入口 | 是 |
| `integrations/geollava/` | 全局路线实际调用的常驻加载与单样本推理函数所在模块 | 是 |
| `scripts/` | 可迁移配置、模型配置视图、预检、启动/停止、API客户端、检查与打包 | 是 |
| `tests/` | 本次发布包装层的附加测试 | 是 |
| `examples/` | 三张小型原图、六个请求模板、三条历史结果（含同题冷/热两次） | 许可核对后提交 |
| `results/historical/` | 独立评测的小型指标文件，不是本次发布全量复测 | 是 |
| `environments/` | 关键依赖版本观测值与安装步骤，不是环境本体 | 是 |
| `assets/` | 数据和模型来源、下载字段、依赖源码逐文件哈希 | 是 |
| `external/` | 与服务端版本相同的第三方源码及补丁 | 单独供给；许可待审，不在Git候选包 |
| `runtime/` | 日志、任务库、临时图像、本机PID信息、模型符号链接视图 | 否 |
| 模型目录 | 基座、适配器、视觉编码器、检索器实际权重 | 否，按比赛要求使用魔搭/百度网盘 |

本次没有移动、删除或修改服务器原始资产。发布候选目录独立于研究工作区；旧试验、GeoChat/AWQ历史模型、第二阶段报告、缓存、整个Conda环境和全量数据集都未混入第一阶段源码包。

维护者注意：复制 `router/` 本身不能复现，因为worker还导入外部辅助脚本和第三方包。具体依赖身份在 `DEPENDENCIES.md`，下载状态在 `assets/DOWNLOADS.md`。
