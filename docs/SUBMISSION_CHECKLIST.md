# 初赛提交前检查

- [ ] 申报表与作品文档齐全，联系人信息准确。
- [ ] 技术报告明确对应第一阶段，不把第二阶段构想写成已实现成果；未经核验的实验标注“待验证”。
- [ ] 源代码、版本号、依赖版本、使用步骤、示例输入及原始输出齐全。
- [ ] 下载清单逐项填写：平台、文件名称和内容、URL、提取码（如有）、权限、版本、使用说明、SHA256。
- [ ] 自训练适配器是本次作品使用的版本，和指定的原始非量化基座匹配。
- [ ] 模型大文件放魔搭/百度网盘；GitHub源码链接不能代替模型链接。
- [ ] 无需提交完整数据集，但应提供官方来源、采用的划分、版本/样本ID及必要示例；核对样例再分发许可。
- [ ] 在干净机器验证下载、校验、配置、环境安装、路由预览及三条真实路线；双图A/B顺序正确。
- [ ] 成功状态、答案质量、解析成功率分开统计；不把队列取消当作真实模型验证。
- [ ] 核对第三方源码/权重/示例的许可和署名，未确认的依赖快照不公开重分发。
- [ ] 运行 `python3 scripts/check_release.py`，检查大文件、敏感信息、运行缓存和缺失资产。
- [ ] 下载链接使用独立账号或无登录环境实测，提取码正确，访问有效期覆盖评审。
- [ ] 邮件提交包用 `申报人所在单位－申报人姓名－作品名称－联系电话.zip` 命名，包内显著说明队伍名称。

当前单位、姓名、队伍、电话按用户要求暂不填写。申报表与最终技术报告由队伍另行确认加入邮件包；第二阶段报告未自动拷入本第一阶段仓库，以免版本混淆。无模型下载链接时提交完整性检查必须报告未完成。
